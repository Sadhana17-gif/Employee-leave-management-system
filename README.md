# Employee Leave Management System

## 📌 Project Description

The **Employee Leave Management System** is a web-based application designed to simplify and manage the employee leave application process.

The system allows employees to apply for leave, view their leave balance, provide leave details, and track their leave requests through a simple and user-friendly interface.

The project is designed with a clean and responsive user interface that can be used on desktop, tablet, and mobile devices.

---

## 🎯 Objectives

* To simplify the employee leave application process.
* To reduce manual leave management.
* To provide an easy-to-use leave application interface.
* To display employee leave balance.
* To maintain leave request details.
* To provide a responsive and professional user interface.

## 🖼️ Main Modules

### 1. Dashboard

The dashboard provides an overview of the employee's leave information and important details.

### 2. Apply Leave

Employees can submit a leave request by entering:

* Leave type
* Start date
* End date
* Reason
* Supporting document

### 3. Leave Balance

The system displays the employee's available and used leave information.

### 4. Employee Information

The system displays basic employee information such as employee name, employee ID, department, and reporting manager.
